Request Data Flow

1
User changes a filter
FilterBar.vue updates refs in useFilters.js composable — shared across all views
2
View reacts
Each view watch()es the composable's filter refs and calls its loadData() function
3
API call via api.js
Axios builds query string — skips params with value 'all'. Example: /api/orders?warehouse=East&status=Shipped
4
FastAPI filters in memory
Endpoint applies sequential list comprehension filters on in-memory data loaded at startup. Month param supports both 2025-01 and Q1-2025 formats.
5
Pydantic validates response
Response serialized through response_model — guarantees shape before JSON is sent
6
Computed properties update UI
Raw data stored in ref(). Derived values (totals, filtered lists, chart data) live in computed() — re-evaluate automatically.
